## 1. บทนำ (Introduction)
ปัจจุบันพฤติกรรมการใช้เครื่องมือสื่อสารและอุปกรณ์อิเล็กทรอนิกส์ก่อนนอน (Screen Time Before Bed) เช่น สมาร์ทโฟน แท็บเล็ต และคอมพิวเตอร์ กลายเป็นหนึ่งในปัจจัยหลักที่รบกวนวงจรการนอนหลับธรรมชาติ (Circadian Rhythm) โดยแสงสีฟ้า (Blue Light) จากหน้าจอส่งผลยับยั้งการหลั่งฮอร์โมนเมลาโทนิน (Melatonin) ซึ่งทำให้ระยะเวลาการเข้าสู่นอน (Sleep Onset Latency) นานขึ้น และส่งผลกระทบเชิงลบต่อคุณภาพการนอนหลับโดยรวม จากการศึกษาชุดข้อมูลพฤติกรรมการนอนและปัจจัยทางสุขภาพของกลุ่มประชากรตัวอย่างจำนวน 374 รายการ ปัจจัยสำคัญที่พบจากการวิเคราะห์เบื้องต้น ได้แก่ ระยะเวลาการใช้หน้าจอก่อนนอน (Screen Time Before Bed) ช่วงอายุ (Age) ระดับความเครียด (Stress Level) พฤติกรรมการดื่มกาแฟและแอลกอฮอล์ รวมถึงตัวชี้วัดทางสุขภาพต่างๆ มาพัฒนาเป็นแบบจำลอง Machine Learning ประเภท xxxxxxxxxxxxxxxxxxxxx เพื่อทำนายความเสี่ยงในการเกิดภาวะผิดปกติเกี่ยวกับการนอนหลับ (Sleep Disorder) สำหรับใช้เป็นเครื่องมือคัดกรองเบื้องต้นและสนับสนุนการปรับเปลี่ยนพฤติกรรมอย่างตรงจุด

## 2. วัตถุประสงค์ (Objectives)
เพื่อสร้างแบบจำลองในการทำนาย/จัดกลุ่ม **[ระบุสิ่งที่ต้องการทำนาย]** โดยสอดคล้องกับ SMART Objectives ที่ตั้งไว้ก่อนหน้า:
* **Specific (เจาะจง):** สร้างแบบจำลอง Machine Learning เพื่อทำนาย...
* **Measurable (วัดผลได้):** โมเดลมีประสิทธิภาพวัดจากค่า Accuracy / Recall / F1-Score ไม่ต่ำกว่า **[ระบุตัวเลข]%**
* **Achievable (ทำได้จริง):** พัฒนาโดยใช้ชุดข้อมูลและอัลกอริทึมมาตรฐานทางด้าน Data Science
* **Relevant (สอดคล้อง):** ช่วยสนับสนุนการตัดสินใจในด้าน...
* **Time-bound (มีกรอบเวลา):** ดำเนินการแล้วเสร็จภายในระยะเวลาที่กำหนดของรายวิชา

## 3. การตั้งคำถาม ระบุ Metric และ KPI และรวบรวมข้อมูลที่เกี่ยวข้อง
3.1 คำถาม (Questions)
- RQ1: ถ้าหากมีความดันโลหิตสูง (Blood Pressure) จะเสี่ยงต่อการเป็นโรคเกี่ยวกับการนอนหรือไม่?
- RQ2: พฤติกรรมการดื่มกาแฟและแอลกอฮอล์มีผลให้เกิดโรคที่เกี่ยวกับการนอนหรือไม่?
- RQ3: หากสามารถลด Screen Time ก่อนนอนลงทุกๆ 15 นาที จะทำให้ไม่เสี่ยงเป็นโรคเกี่ยวกับการนอน?
- RQ4: ระยะเวลาทานอาหารมื้อสุดท้ายก่อนนอน ส่งผลการเกิดโรคเกี่ยวกับการนอนหรือไม่?

3.2 การกำหนด Metrics และ KPIs
- **Metric (ตัวแปร):** ปัจจัยหลักที่มีความสัมพันธ์ต่อการเกิดภาวะผิดปกติของการนอนหลับ
- **KPIs (ตัวชี้วัดผลลัพธ์):**
  1. **Blood Pressure:** คะแนนคุณภาพการนอนหลับเฉลี่ย (เป้าหมาย: เกณฑ์ปกติ < 120/80 mmHg)
  2. **Caffeine Intake (cups/day):** ปริมาณการดื่มกาแฟเฉลี่ยต่อวัน (เป้าหมาย: ≤ 2 แก้ว/วัน)
  3. **Alcohol Consumption (drinks/week):** ปริมาณการดื่มแอลกอฮอลเฉลี่ยต่อสัปดาห์ (เป้าหมาย: ≤ 2 แก้ว/สัปดาห์)
  4. **Screen Time Before Bed (mins):**  ระยะเวลาการใช้หน้าจอก่อนเข้านอน (เป้าหมาย: ≤ 45 นาทีก่อนนอน)
  5. **Last Meal Before Bed (hours):** ระยะเวลามื้ออาหารสุดท้ายก่อนนอน (เป้าหมาย: ≥ 3 ชั่วโมงก่อนนอน)

## 4. Data Dictionary

### ตัวแปรเป้าหมาย (Target Variable)
* `ชื่อคอลัมน์เป้าหมาย` (ประเภทข้อมูล): คำอธิบายความหมาย (เช่น `1` = เกิดเหตุการณ์, `0` = ไม่เกิดเหตุการณ์)

### ตัวแปรอิสระ (Features)
| ชื่อตัวแปร (Feature) | ประเภทข้อมูล (Data Type) | คำอธิบาย (Description) |
| :--- | :--- | :--- |
| `Feature_1` | Integer / Float | คำอธิบายตัวแปรที่ 1 |
| `Feature_2` | Categorical | คำอธิบายตัวแปรที่ 2 (เช่น M = ชาย, F = หญิง) |
| `Feature_3` | Integer | คำอธิบายตัวแปรที่ 3 |

## 5. การวิเคราะห์ข้อมูลเชิงสำรวจ (EDA)
สรุปสิ่งที่ค้นพบจากการสำรวจข้อมูลเบื้องต้น:
* **การกระจายตัวของ Target (Class Balance):** ระบุสัดส่วนของข้อมูลเป้าหมาย (เช่น กลุ่ม 1 มี 55% และกลุ่ม 0 มี 45%)
* **ความสัมพันธ์ของตัวแปร (Correlation):** ระบุตัวแปรที่มีความสัมพันธ์กับตัวแปรเป้าหมายอย่างมีนัยสำคัญ
* **ความผิดปกติของข้อมูล:** ระบุค่าว่าง (Missing Values) หรือค่าผิดปกติ (Outliers) ที่ตรวจพบ
